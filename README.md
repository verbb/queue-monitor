<h1 align="center">Queue Monitor for Craft CMS</h1>

Queue Monitor is a Craft CMS plugin that watches Craft's background jobs and tells the right people when processing has stalled or failed. Catch a broken queue before an editor or customer has to discover the consequences.

Monitor Craft's queue for jobs that have failed and send a notification with a direct route back to the relevant control-panel screen. Teams can respond to interrupted imports, emails, transforms, and other background work without checking the queue manually.

## Features

- Watch the background jobs Craft and installed plugins create.
- Identify failed work that would otherwise sit unnoticed.
- Retry failed jobs according to the project's configured limits.
- Notify the people responsible for keeping the site healthy.
- Send queue failures and stalled-queue warnings to another monitoring service.
- Point recipients back to the queue information in Craft.
- Configure monitoring so alerts reflect the project's operational needs.
- Add awareness while leaving queue management with Craft.
